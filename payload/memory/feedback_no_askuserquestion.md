Never use the AskUserQuestion tool in this repo. Ask questions directly in chat as plain text.

**Why:** Owner prefers inline answers over the structured multiple-choice UI.
**How to apply:** When a decision needs owner input, pose the question as ordinary chat text (with options listed in prose if helpful) and wait for the reply.
